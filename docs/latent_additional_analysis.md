# 潜在変数予測の追加解析：重みとマスクの分離

既存の `experiments/latent_linear/` を読み取り、NNを再学習せずに解析する。
既存の各MLP・連結特徴のRidge評価は再計算のために学習し直さず、保存済み回帰器で
予測値とスコアの一致を検証して再利用する。不足していた隠れ層の非線形回帰だけを追加する。
GraN-DAGの損失、DAG制約、最適化、既存の評価処理は変更しない。

## 実行方法

リポジトリ直下で実行する。最初の実行は既に完了している。

```bash
bash run_in_container.sh python latent_additional_analysis.py \
  --run-dir experiments/latent_linear
```

出力先は `experiments/latent_linear/additional_analysis/`。
既存の出力先がある場合は**停止**する。再現実行には新しい出力先を指定する。

```bash
bash run_in_container.sh python latent_additional_analysis.py \
  --run-dir experiments/latent_linear \
  --output-dir experiments/latent_linear/additional_analysis_repeat
```

出力先は元の実験ディレクトリ直下の新しいディレクトリに限定する。
既存の `analysis/`、モデル、隠れ層を上書きするオプションは設けていない。
全既存ファイルのSHA256を解析前後に比較し、変更があればエラーにする。
通常のPyTorch/scikit-learn環境でも実行可能だが、pickleの互換性のため保存時と同じ
準備済みコンテナ（PyTorch 1.1、scikit-learn 0.21）を推奨する。
pickleはこの実験で生成した信頼できるものだけを読み込む。

## 比較条件

|条件|NNの重み|入力マスク|
|---|---|---|
|A|実際の学習前チェックポイント|初期の全非自己辺|
|B|同じ学習前の重み|NN学習終了時|
|C|NN学習終了時の重み|NN学習終了時|
|D|同じ学習前の重み|DAG化後|
|E|Cと同じ学習済みの重み|DAG化後|
|F|同じ学習前の重み|CAM pruning後|
|G|Cと同じ学習済みの重み|CAM pruning後|

学習効果はB→C、D→E、F→G、マスクの効果はC→E→GとB→D→Fで比較する。
A→Cは学習とマスクが両方変化するため、純粋な学習効果とは区別する。
現在の実験ではDとF、EとGはそれぞれ同一になることを検証した。
チェックポイントの全登録パラメータ（バイアス・ノイズパラメータを含む）と構造を
ハッシュで照合し、マスクも別途照合する。

各条件に該当する既存の隠れ層を選び、全サンプル・全隠れ層について固定NNでの
再計算と照合する。入力の標準化も元の学習用平均・不偏標準偏差との一致を検証する。
該当するチェックポイントがない条件は、元の初期重みまたは学習済み重みをコピーし、
マスクだけを変更して既存の `save_hidden_activations()` で新規出力先へ抽出する。
元のモデルや隠れ層には書き込まない。

## 回帰とデータ分割

- 学習600件、検証200件、最終テスト200件の既存分割を維持する。
- 元の `fit_probe()` と `evaluate_probe()` を再利用する。
- RidgeのStandardScalerとalpha選択は学習データ内だけで行われた既存回帰器を使う。
- 隠れ層にはExtraTrees回帰を追加する。候補は元のX回帰と同じ：木100本、
  max_depthはNone/5/10、min_samples_leafは2/5。seed43、学習内5分割CVのMSEで選択する。
- テスト・検証データを新規回帰のfitや候補選択に渡さない。
- 同一特徴配列・同一回帰手法・同一Zの結果だけを共有して重複fitを避ける。
- RidgeとExtraTreesの両方を報告し、テストスコアで採用手法を選ぶ処理は設けない。
- 元のテスト200件は既に閲覧済みであり、今回の追加比較は探索的解析。
  独立した確認実験や一般的な優位性の検証とは区別する。

隠れ層は元の `(1000, 3, 10)` を使用。X1等は「その変数を予測するMLP」の意味。
個別MLPの10特徴と、全MLPを連結した30特徴をそれぞれ使用する。
定数特徴も削除せず評価し、`varying_features=0` と親数0を明示する。

## 実行済みの結果

初期設定の既存線形データで追加解析を実行した。NN再学習0回、隠れ層の新規複製0件、
新規回帰fit31件、既存回帰再利用33件。同じ特徴の結果を共有し、合計114行の評価、
22,800行のテスト予測、PNG8枚を保存。解析は約75秒だった。
既存203ファイルのハッシュ不変を検証済み。
保存された全114件のR²/MSEをテスト予測CSVから独立に再計算し、
サンプルID・Zの対応、各条件のテスト200件の重複なしも確認した。

主なテスト結果（R²）：

|特徴|Ridge 第1層|Ridge 第2層|ExtraTrees 第1層|ExtraTrees 第2層|
|---|---:|---:|---:|---:|
|B：未学習・学習後マスク、連結|0.9255|0.9255|0.9076|0.9049|
|C：学習済み・学習後マスク、連結|0.9220|0.7910|0.9075|0.9062|
|E：同じ学習済み重み・DAGマスク、連結|0.9003|0.9000|0.8968|0.8973|
|C：X1のMLP|0.8954|0.8945|0.8902|0.8897|
|C：X2のMLP|0.5208|0.5100|0.4917|0.4848|
|C：X3のMLP|0.7770|0.2641|0.7817|0.7838|

元のXのRidgeはR²=0.925652、MSE=0.070587、ExtraTreesはR²=0.911778、MSE=0.083759。
学習済み個別MLPで最も予測できたのはX1の第1層（Ridge R²=0.895356、MSE=0.099351）。
全条件を含む個別MLPのRidge最高値はAのX3第2層（R²=0.926322）であり、
未学習NNからも良好に予測できる。学習済みMLPの最高値とは区別する。

第2層のRidgeが低いことだけでは、Zとの予測可能な依存性が消えたとはいえない。
特にCのX3第2層はRidgeのR²=0.264123、MSE=0.698650に対し、
ExtraTreesではR²=0.783845、MSE=0.205220となった。
Cの連結第2層もExtraTreesでは0.906184まで予測できた。

同じマスクのBとCでは、NN学習による一貫した改善は認められない。
連結ExtraTreesの第2層は+0.001304だが、第1層は−0.000083であり、
一つのテストでの小差から優位性を主張しない。

DAG化はX1→X3を除去し、X3のMLPを定数にした。残るグラフはX3→X2→X1。
X3のテストR²は両手法・両層でほぼ0（厳密には−0.000004683）、MSE=0.949416。
X1とX2の特徴は変わらない。CAMはこのケースでは追加で枝を除去せず、追加変化もない。
連結のExtraTreesはDAG化で第1層0.9075→0.8968、第2層0.9062→0.8973と低下した。
一方、連結Ridge第2層は0.7910→0.9000に上がった。
これは選んだ回帰手法のテスト予測性能の変化であり、「マスク削除で情報量が増えた」
ことを意味しない。

以上は特定の分布・一つの学習シードにおけるZの予測可能性の結果であり、
潜在変数の自動発見、因果的な意味の同定、情報量の直接測定ではない。
多シード・別生成条件・新しい最終テストでの確認実験は今回実施していない。

## テスト

```bash
bash run_in_container.sh env OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  python -m unittest discover -s tests -v
```

追加テストは `tests/test_latent_additional.py`。
出力先保護、元ファイルのハッシュ保護、マスクを除くパラメータ同一性、
キャッシュと固定NNの一致・破損検出、学習用データのみを回帰fitに渡すこと、
既存Ridge再利用・スコア再計算、比較差分の符号を検証する。
既存12件と追加5件、合計17テストはすべて実行して成功した。
